# Demo plan

The numerical engine, scientific diagnostics and controlled benchmark are
implemented through Milestone 2. The application/agent/repair workflow below
remains a proposed demo sequence:

1. Select an advection scenario.
2. Run the baseline numerical experiment.
3. Inspect conservation and accuracy diagnostics.
4. Generate a repair proposal.
5. Validate the candidate and compare results.
6. Save the experiment outputs in `artifacts`.

Add setup commands, expected results, and fallback examples once these steps are
implemented.
